# POS Android Application

## English

A clean, efficient, and offline-first Point of Sale (POS) application built with **Kotlin** and **Jetpack Compose**.

### Features
- **Product Management**: Easily manage your product catalog, including adding new products and updating existing prices/details.
- **POS System**: Create sales transactions with an intuitive cart system.
- **Cart Logic**: Automatically calculate subtotals, apply percentage-based discounts, and calculate tax. Includes support for wholesale pricing based on quantity.
- **Data Persistence**: Uses a local **Room Database** to store products, sales history, and expense logs securely without needing a backend server.
- **Visual Analytics**: Interactive visualization of sales and expenses over time.

### In Development / Maintenance
- **QR Code Scanner**: The QR code scanning functionality is currently under repair.

### How to Install and Run in Android Studio
1. **Prerequisites**: Ensure you have **Android Studio** (recommended: latest stable version) installed.
2. **Clone the Repository**: Clone this project to your local machine:
   ```bash
   git clone <your-repository-url>
   ```
3. **Open Project**:
   - Open Android Studio.
   - Select **File > Open** and navigate to the root directory of the cloned project.
4. **Gradle Sync**: Once opened, Android Studio will automatically attempt to sync Gradle. Wait for the process to complete.
5. **Set Up Emulator/Device**: Ensure you have an Android device connected or an Android Emulator configured.
6. **Run the App**: Select the `app` configuration in the toolbar and click the **Run** (green play icon) button.

## Bahasa Indonesia

Aplikasi Point of Sale (POS) yang bersih, efisien, dan offline-first dibangun dengan **Kotlin** dan **Jetpack Compose**.

### Fitur Utama
- **Manajemen Produk**: Kelola katalog produk dengan mudah, termasuk menambah produk baru dan memperbarui harga/detail.
- **Sistem POS**: Sistem transaksi yang intuitif dengan fitur keranjang.
- **Logika Keranjang**: Perhitungan subtotal, diskon, dan pajak otomatis. Mendukung tier grosir berdasarkan kuantitas.
- **Penyimpanan Data**: Menggunakan **Room Database** lokal untuk menyimpan produk, riwayat penjualan, dan log pengeluaran dengan aman tanpa perlu server backend.
- **Visualisasi Analytics**: Visualisasi interaktif penjualan dan pengeluaran dari waktu ke waktu.

### Dalam Perbaikan
- **QR Code Scanner**: Fitur scanning QR Code saat ini sedang dalam perbaikan.
